# Short skill names and shared project entry

Use eight discoverable names: project, frontend, design-context, ux, debug,
safe-change, verify, and handoff. Keep precise task signals in descriptions.
Merge project explanation and architecture assessment into project modes that
share inspected evidence. Preserve explanation-only, assessment-only, and
combined requests without changing the read-only authority boundary. Move rescue
coordination into a documented recovery workflow, retaining its agreed-scope
and verification rules. Update active references, metadata, README, and cases.
Preserve historical evaluation snapshots and prior work records as evidence.
